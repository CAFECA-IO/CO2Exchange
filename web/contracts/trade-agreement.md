# 減量額度買賣定型化契約

**本文件為 Phase 0 展示範本，非法律意見，正式上線前應經法遵與律師審閱。**

## 第一條　契約當事人與平台地位

本契約當事人為賣方與買方（下稱「雙方」），均為已完成 CO2Exchange 平台身分驗證之用戶。

卡菲卡股份有限公司（下稱「本公司」）**非本契約當事人，亦不持有本契約標的之減量額度**；其地位為**見證人與履約輔助人**，負責撮合、鏈上交割、資訊公告，及於最終買方申請註銷時，協辦專案方與該買方間之官方移轉與註銷程序。

## 第二條　契約標的

本契約標的以下單時系統帶入並經雙方確認之數值為準：

| 專案名稱與編號 | `{{projectName}}` / `{{projectId}}` |
| 專案類型 | `{{projectType}}` |

依溫室氣體減量額度交易拍賣及移轉管理辦法第十二條，定價交易上架時應申報減量額度之使用期限及用途；前開使用期限由賣方於掛單時申報，並隨掛單公告。

前開資料與官方登錄簿所載不一致者，以官方登錄簿為準。

## 第三條　價金與交付（原子交割）

買方應於下單時將全額價金存入鏈上交割合約（Phase 0 為鏈上測試代幣 MockTWD，不涉及真實資金；正式營運時價金存入金融機構信託專戶或履約保證專戶，與本公司自有資金分離）。交割以**原子交易**執行：價金撥付賣方與鏈上額度移轉予買方於同一筆鏈上交易完成，任一方失敗即全部回復原狀，不生部分履行。手續費於交割時扣收，雙方各負擔其應付部分。交割完成後本公司應即於鏈上公告欄公告。

## 第四條　權利移轉之性質與官方移轉之時點

一、**額度之登錄位置**：本契約標的自中央主管機關核撥時起（溫室氣體自願減量專案管理辦法第二十二條），即登錄於**專案方自有之額度帳戶**內，卡菲卡股份有限公司不持有該額度，亦非本契約之買賣當事人。以官方登錄簿紀錄為準。

二、**本契約所移轉者**，為「**對該批減量額度之請求權**」，即請求專案方於買方依法申請註銷時配合辦理官方移轉之權利，非官方登錄簿上之登記名義。

三、依溫室氣體減量額度交易拍賣及移轉管理辦法第二十六條，「每減量額度單位移轉次數，以一次為限」；同辦法第二條第六款所定「移轉」，限於完成交易或拍賣後由中央主管機關將賣方事業額度帳戶項下之額度移轉至買方事業額度帳戶項下之行為。本契約之鏈上交割**不觸發亦不消耗**該唯一一次之移轉次數，買方於本平台得再次轉售。

四、**官方移轉之時點與路徑**：該唯一一次之官方移轉，於**最終買方申請註銷時**發生，路徑為**專案方額度帳戶 → 該買方額度帳戶**；其後由該買方以自己名義向中央主管機關申請註銷。本公司為協辦與協調者，非移轉之一方。

五、賣方擔保就標的有完整處分權，該額度確已核撥並登錄於專案方額度帳戶、未曾辦理官方移轉、未經註銷、未於其他制度重複登錄或主張；賣方非專案方者，並擔保其自專案方取得之請求權鏈完整且未中斷。

## 第五條　雙方之配合義務

**（一）賣方**：掛單時提供正確之額度編碼、專案資訊、監測期間及使用期限；不得就同一額度於本平台外另行處分或設定負擔。**賣方為專案方者，應於最終買方申請註銷時，配合將該額度自其自有額度帳戶移轉至該最終買方之額度帳戶**——配合之對象為最終買方，而非本公司或本平台；並應於接獲通知後**七日內**備齊交易或拍賣後移轉所需文件，回應中央主管機關之補正要求。本項義務於鏈上交割完成後仍繼續存在，至該筆額度完成官方註銷或經主管機關撤銷時止。

**（二）賣方之知悉與同意**：賣方知悉並同意，拒絕或無故拖延配合官方移轉程序者，該批額度**無法於本平台上架**，且**自始不適用**「代辦服務費用與減免約定書」所定之每噸費用減免；已減免者，本公司得依該約定書第六條、第七條追繳。

**（三）買方**：提供正確有效之統一編號或身分證統一編號、名稱及聯絡電子郵件；註銷時據實聲明用途（限扣除碳費排放量、自願性碳中和或碳抵換、溫室氣體增量抵換、環評承諾事項四類之一）；於通知所定期限內簽署或用印必要文件；不得於官方申辦程序中無正當理由撤回。

**（四）共同**：身分資料、聯絡方式或代表人有變更者，應於變更之日起**十四日內**於本平台更新。

**（五）自然人買方之權利範圍**：依溫室氣體減量額度交易拍賣及移轉管理辦法第二條第一款，「事業」不含自然人；同辦法第七條開立額度帳戶須檢附經目的事業主管機關核准設立、登記或營業之證明文件。自然人無從開立額度帳戶，故買方為自然人時，其依本契約取得之權利**以持有及再次轉售為限，不包含申請官方移轉與註銷**；其取得之鏈上紀錄**非官方註銷證明**，不得用於碳費扣抵、環評增量抵換、環評承諾事項或任何法定申報。買方為自然人者，應於下單介面勾選確認已明瞭並同意本款；未經確認者系統不予受理下單。

## 第六條　不配合之認定、催告與補正

**（一）認定**　有下列情形之一者，認定為違反第五條之配合義務：
1. 經依本條催告，於補正期限屆滿仍未提供正確資料或未完成簽署、用印。
2. 所提供之統一編號、身分資料或受益人資料經查證不實或已失效，且未於補正期限內更正。
3. 於官方申辦程序進行中，無正當理由撤回申請或明示拒絕協力。
4. 就同一額度於其他制度重複主張或重複使用。
5. 賣方撤回掛單後，未於撤回之日起三十日內就同一數量重新上架（僅生第七條第一款之效果）。

**（二）催告**　他方或本公司應以站內通知**併同**電子郵件送達催告，載明應補正事項、依據、期限及逾期效果。通知發送至用戶登錄之電子郵件信箱後**第三日推定送達**。

**（三）補正期限**
1. 一般情形：通知送達後**七日內**完成。
2. 中央主管機關另定期限者：應於該期限屆滿前**二個工作日**完成，且不得短於通知送達後三個工作日；期限過短無法遵期者，應於期限內敘明並申請展延。
3. 因天災、疾病或其他不可歸責事由未能遵期者，得於事由消滅後**五日內**檢具證明申請展延，以一次、十四日為限。

**（四）代行**　經合法催告且期限屆滿仍未補正，而該事項得由本公司依既有授權代為辦理者，本公司得代為辦理，必要費用由不配合之一方負擔。

## 第七條　違約責任與損害賠償

經依第六條認定為不配合且未於補正期限內補正者，其效果分為二層：

**（一）主要效果——費用減免失效與追繳（賣方）**　賣方不配合者，該批額度**無法上架**，並**自始不適用**「代辦服務費用與減免約定書」所定之每噸費用減免；已減免者，本公司得依該約定書第六條、第七條**追繳已減免金額**，並自催告所定繳納期限屆滿之次日起按年息百分之五計息，必要時自賣方在本平台之待結算價金中抵充。本款效果不以買方或本公司先行舉證損害為前提。

**（二）補充效果——違約金與損害賠償**　本款僅適用於**該額度已成交後始不配合，致買方或第三人實際受有損害**之情形：
1. **違約金**：按本契約總價之**百分之三**計算，作為對造處理延宕所生勞費之最低補償；總價未達新臺幣一萬元者，以新臺幣三百元為限。
2. **損害賠償**：所受損害超過前目違約金者，得就超過部分請求。範圍以與不配合行為具**相當因果關係之實際損害**為限，包含：重新辦理官方申辦所生之規費、公證費、鑑定費；因延宕須另行購入等量額度之價差；因逾期未能完成碳費扣抵或環評抵換而實際支出之差額；必要律師費，以新臺幣五萬元為上限。**不含**所失利益、商譽損害及其他間接損害；但有故意或重大過失者不在此限。
3. **不重複填補**：同一事由已依前款追繳者，追繳金額於計算本款賠償時應予扣除。

**（三）賠償總額上限**　除故意或重大過失外，依前款第 2 目請求之賠償總額以本契約總價之**二倍**為上限。

**（四）免責**　不配合係因下列事由所致者不負本條責任：不可抗力；本公司系統故障或通知未依第六條第二款送達；中央主管機關程序或見解變更；他方未先行履行其協力義務。

**（五）公平性**　本條義務與責任於買賣雙方均予適用。買方為自然人消費者時，本條違約金及賠償上限規定，於對買方不利之範圍內不予適用；第一款之費用減免與追繳機制，僅適用於代辦委任關係下之賣方，不適用於買方。

## 第七條之一　替代履行：等值額度替換（買方之第一順位救濟）

**（一）觸發要件**　專案方經依第六條合法催告後，仍拒絕或無故拖延將該額度移轉予最終買方，且逾補正期限者，買方得依本條請求替代履行。本條為買方之**第一順位救濟**，優先於第七條第二款之違約金與損害賠償。

**（二）本公司之義務**　本公司應於認定不配合之日起**十四日內**，自其他來源取得**等值減量額度**供該買方使用，其取得與移轉之程序由本公司協辦。

**（三）「等值」之定義**　替代額度須同時符合下列三項：
1. **年份**：與原額度同一監測期間年份（vintage），或**更新之年份**；以更新年份替代者，買方不得因此要求補足差價，本公司亦不得請求加價。
2. **用途相容**：得用於買方原申報之用途，即扣除碳費排放量、自願性碳中和或碳抵換、溫室氣體增量抵換、環評承諾事項四類中之同一類。
3. **數量**：與原契約數量相同。

買方原用途無法以替代額度達成者（例如環境影響評估承諾事項指定特定專案之額度），不適用替換，改依第五款解除契約並退還價金。

**（四）買方之選擇權**　本公司應以站內通知併同電子郵件告知替代額度之編碼、專案、監測期間及數量。買方得於**通知送達後七日內**選擇接受替換，或**解除本契約並取回全額價金及已繳手續費**；逾期未表示者，**視為接受替換**。

**（五）無法取得替代額度時**　本公司未能於第二款所定十四日內取得符合第三款之替代額度者，應於期限屆滿後**三個工作日內**通知買方，全額退還價金及手續費，並另按本契約總價之**百分之三**補償買方。本款補償與第七條第二款第 1 目之違約金**不重複計算**，擇高適用。

**（六）費用負擔與追償**　替換所生之價差、規費及必要費用，由本公司先行負擔，再依「代辦服務費用與減免約定書」第六條、第七條向不配合之專案方追償；其超出已減免代辦費之部分，性質為損害賠償，適用第七條第三款之上限規定。買方已受替換或補償者，就同一損害不得再向專案方重複請求。

**（七）性質與 Phase 0 之限制**　本條為本公司之**自願性服務承諾**，非法定義務，其財源為本公司之代辦服務費與交易手續費收入。**Phase 0 展示階段，本公司尚未具備實際履行能力**（無真實資金流與額度庫存），本條於本階段僅具宣示意義；正式營運前，本公司應建立替換準備機制（含備援額度來源、準備金或保險安排），並於平台公告其內容。

## 第八條　瑕疵擔保

標的經中央主管機關撤銷、註記無效或認定不得使用者：

一、**交割前**發生者，本契約當然失效，價金及手續費全額退還買方。
二、**交割後、註銷前**發生且可歸責於賣方（含減量成效未實際發生、資料不實）者，賣方應於買方通知送達後**三十日內**返還全部價金及自交割日起按年利率百分之三計算之利息；買方亦得選擇由賣方以同類型等量額度替代。
三、**註銷後**發生者，賣方應返還價金並協助辦理更正程序。
四、不可歸責於雙方者（如法令變更），由雙方按實際損失協議分擔，協議不成依第十條處理。

## 第九條　不可歸責事由

因天災、政府命令、法令變更、區塊鏈網路中斷或其他不可抗力致遲延或不能履行者，不負遲延責任，但應於事由發生後**三日內**通知他方及本公司。事由持續逾**六十日**者，任一方得書面終止本契約，已交割部分回復原狀。

## 第十條　爭議處理

雙方應先本於誠信協商；協商不成者，得請求本公司提供鏈上交易、公告及通知送達紀錄作為證據，並得申請本公司調處，其意見不具拘束力。仍未解決者，合意以**臺灣臺北地方法院**為第一審管轄法院。買方為消費者時，不排除其依消費者保護法申訴或調解之權利。本契約以中華民國法律為準據法。

## 第十一條　契約審閱期

買方為自然人時，本公司已依消費者保護法第十一條之一規定，於本契約成立前提供**不少於三日**之合理審閱期間，並於介面顯著位置提供全文供其下載留存。

買方應於介面勾選確認「本人已於下單前取得本契約全文，並已獲得不少於三日之審閱期間」；未經勾選者系統不予受理下單。買方於審閱期間內得隨時終止締約程序，不負任何費用。

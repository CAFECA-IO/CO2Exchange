# CO2Exchange 平台使用約定書

**本文件為 Phase 0 展示範本，非法律意見，正式上線前應經法遵與律師審閱。**

用戶使用本平台服務前應閱讀並同意本約定書，勾選同意後生效。**「服務流程說明書」為本約定書之附件，隨本約定書生效，無須另行簽署**；其所載流程與期限具契約拘束力，與本約定書或其他契約條文有出入者，以各該契約條文為準。

## 第一條　名詞定義

一、**本公司**：卡菲卡股份有限公司（CAFECA），本平台建置者與代營運者。
二、**本平台**：本公司營運之「CO2Exchange」減量額度交易平台。
三、**官方登錄簿**：中央主管機關（環境部）之「溫室氣體減量額度管理系統」（tcerregistry.moenv.gov.tw）。
四、**減量額度**：依氣候變遷因應法第二十五條執行自願減量專案取得，並登錄於官方登錄簿者。
五、**事業**：依溫室氣體減量額度交易拍賣及移轉管理辦法第二條第一款，指公司、行號、工廠、民間機構、行政機關（構）及其他經中央主管機關公告之對象，包括各級政府；**不含自然人**。
六、**額度帳戶**：事業依同辦法第七條檢附經目的事業主管機關核准設立、登記或營業之證明文件，於官方登錄簿開立之帳戶。
七、**專案方**：執行自願減量專案、經中央主管機關核撥減量額度至其自有額度帳戶之事業；於本平台首次出售該額度時即為賣方。
八、**鏈上額度**：本平台於區塊鏈為用戶記錄之請求權單位，性質依第三條定之。
九、**智能帳戶**：用戶以 passkey（通行金鑰）為唯一控制憑據之鏈上帳戶。

## 第二條　帳戶開立與身分驗證

法人用戶以工商憑證驗證，提供統一編號、名稱及代表人資料；自然人用戶以自然人憑證或行動自然人憑證（TW FidO）驗證，提供姓名及身分證統一編號。驗證效期與所用憑證一致；憑證失效者交易功能即停止，但已持有之鏈上額度仍得持有及申請註銷。

法人用戶如擬於本平台出售自有專案額度，或擬買受額度並申請註銷者，應另於官方登錄簿開立額度帳戶（交易拍賣及移轉管理辦法第七條），並於本平台登錄該帳戶編號；本公司得協助辦理。

**Phase 0 特別說明**：本階段身分驗證為模擬，管理員核准即視為通過，未介接憑證管理中心，不具官方驗證效力。

## 第三條　減量額度之登錄架構與代辦關係（重要揭露）

一、**本公司不持有任何減量額度**。依溫室氣體自願減量專案管理辦法第二十二條，中央主管機關核定減量額度後，係核撥至**事業自己於指定資訊平台之帳戶**；本平台之減量額度因此自核發之時起，全程**登錄於專案方自有之額度帳戶內**，本公司僅提供代辦申請、平台撮合、鏈上登錄及移轉與註銷程序之協辦。

二、依溫室氣體減量額度交易拍賣及移轉管理辦法第二條第六款，「移轉」指**完成交易或拍賣後**，由中央主管機關將賣方事業額度帳戶項下之減量額度移轉至買方事業額度帳戶項下之行為；法規並無為保管目的而移轉之類型。另依同辦法第五條，賣方限於已執行自願減量專案、抵換專案或先期專案**並取得持有**減量額度之事業。本公司既非額度持有人，不具賣方資格，亦不得為保管而受領移轉。

三、用戶於本平台鏈上持有者，為「**對該批減量額度之請求權**」，即請求專案方於用戶依法申請註銷時，配合辦理官方移轉之權利；此**非**官方登錄簿上之登記名義，用戶亦非官方登錄簿之帳戶持有人。

四、**官方登錄簿之紀錄為準**；鏈上紀錄與之不一致時，本公司應即更正並公告。

五、依交易拍賣及移轉管理辦法第二十六條，「每減量額度單位移轉次數，以一次為限」。用戶於本平台之多次買賣屬前開請求權之移轉，**不觸發亦不消耗官方移轉次數**；買方於本平台得再次轉售，轉售次數不影響官方登錄簿。

六、該唯一一次之官方移轉，於**最終買方申請註銷時**發生，路徑為**專案方額度帳戶 → 最終買方額度帳戶**，其後由該買方以自己名義向中央主管機關申請註銷。本公司為代辦與協調者，**非移轉之當事人**。

七、因前項架構，**專案方之配合義務為本平台之核心**：其違反者，依「代辦服務費用與減免約定書」不得上架、不適用每噸費用減免，已減免者並予追繳。

## 第三條之一　自然人使用者之權利與限制（重要揭露）

一、依交易拍賣及移轉管理辦法第二條第一款，「事業」不含自然人；同辦法第七條開立額度帳戶須檢附經目的事業主管機關核准設立、登記或營業之證明文件。**自然人無從開立額度帳戶**，因而無法受領官方移轉，亦**無法於官方登錄簿完成註銷**。

二、自然人使用者於本平台**得買受、持有及再次出售**鏈上額度，**不得申請註銷**。本平台身分登錄合約於自然人帳戶提出註銷請求時將予擋下。

三、自然人使用者取得之鏈上紀錄、交易明細或持有證明，**均非官方註銷證明**，**不得用於碳費扣抵、環評增量抵換、環評承諾事項或任何法定申報**，亦不得據以對外進行碳中和或碳抵換之聲明。

四、自然人使用者如需實際使用該額度，應將其鏈上額度出售予具備額度帳戶之事業，由該事業依前條第六項程序辦理。

## 第四條　本平台之角色

本平台之角色為**交易撮合、請求權登錄、資訊公開及移轉與註銷程序之協辦**，既非過戶機關，亦非額度持有人或買賣之當事人；官方移轉之核准與執行專屬於中央主管機關，註銷申請人為取得額度之買方事業本身。本公司不對額度價格、流動性或未來可扣抵數量作任何保證。

## 第五條　智能帳戶與金鑰保管

passkey 私鑰儲存於用戶自有裝置之安全區域，本公司不持有、不備份、無從還原，用戶應自負保管責任。

遺失裝置或無法使用 passkey 者，得檢具有效憑證申請帳戶回復（recover），由本公司將控制權移轉至新登錄之 passkey；回復程序不得作為變更額度歸屬之途徑。

## 第六條　交易、註銷與鏈上公告

用戶得以定價掛單買賣鏈上額度，雙方權利義務依「減量額度買賣定型化契約」定之；本公司為見證與履約輔助者，非契約當事人。

**具備額度帳戶之事業**申請註銷時，應另簽署「註銷暨移轉委任書」，委任本公司協辦官方移轉與註銷程序，並就下列四類用途擇一聲明：扣除碳費排放量、自願性碳中和或碳抵換、溫室氣體增量抵換、環評承諾事項。註銷申請人為該事業自己，本公司僅代為備文、送件並聯繫專案方與主管機關。自然人使用者依第三條之一不得申請註銷。

依交易拍賣及移轉管理辦法第二十七條，中央主管機關應於註銷次日起五個工作日內公開用途；**經公開後事業始得對外進行環境聲明或宣告**。

本平台設鏈上公告欄，額度之**核發、移轉、註銷**均即時公告。

## 第七條　用戶之配合義務

用戶應配合鏈上額度移轉及後續官方移轉與註銷程序，包括提供正確有效之統一編號、額度帳戶編號、身分及受益人資料，於通知所定期限內簽署或用印必要文件，且不得於程序進行中無正當理由撤回或拒絕協力。**專案方並應於最終買方申請註銷時，配合將該額度自其額度帳戶移轉至該買方額度帳戶。**

**配合義務之主要拘束力為費用機制而非訴訟**：委由本公司代辦自願減量專案之用戶，其額度上架本平台者，依「代辦服務費用與減免約定書」享有每公噸代辦費減免；拒絕或無故拖延配合官方移轉者，該額度無法上架、自始不適用減免，已減免者並予追繳。其事由、催告、繳納期限與抵充，依該約定書辦理。

用戶違反前項義務致交易對方、本公司或第三人受有損害者，另負賠償責任；其認定、催告、補正期限及賠償範圍，依「減量額度買賣定型化契約」及「註銷暨移轉委任書」之約定辦理。

**買方之第一順位救濟**：專案方經催告後仍拒絕或無故拖延移轉予最終買方者，本公司依「減量額度買賣定型化契約」第七條之一，於認定後十四日內為該買方取得等值減量額度（同年份或更新年份、用途相容、數量相同）；無法取得者全額退款並補償總價百分之三。該條為本公司之自願性服務承諾，Phase 0 尚未具備實際履行能力。

**上架資格**：未簽署「代辦服務費用與減免約定書」者，或已發生追繳而尚未清償者，本公司得拒絕其新掛單，並應以站內通知併同電子郵件敘明理由；清償或爭議經釐清後，應即恢復掛單功能。

本公司得收取交易撮合手續費（按成交總價比率計收，雙方各負擔其應付部分）、註銷代辦服務費（按件計收）、專案代辦服務費（依「代辦服務費用與減免約定書」按公噸計收並得減免），及依法代墊之規費。費率公告於費用頁面；調整應於生效日前三十日公告，調整前已成交或已受理之案件適用舊費率。

## 第九條　帳戶之暫停、限制與終止

有下列情形之一者，本公司得暫停或限制交易功能，並於處置後三日內以電子郵件敘明理由通知：憑證失效或經撤銷；經司法或行政機關通知凍結；有事證顯示帳戶遭冒用；所提供資料經查證不實。事由消滅後用戶得申請恢復，本公司應於七個工作日內回覆。

用戶得隨時申請終止帳戶，但應先了結未完成之掛單、交易及註銷程序；仍持有鏈上額度者，應先行出售或申請註銷。

蒐集、處理及利用個人資料之目的，限於身分驗證、交易撮合、官方申辦、法定申報及客服聯繫。

**公開於鏈上公告欄者**限於額度編碼、專案名稱與類型、監測期間、數量、交易時間、成交價格及智能帳戶地址；**不公開**姓名、身分證統一編號、聯絡方式及身分文件。但法人用戶註銷時，其名稱、統一編號及用途屬依法應公開事項，將隨官方程序揭露。用戶得依個人資料保護法請求查詢、補正或刪除。

## 第十一條　風險揭露

一、**Phase 0 無法律效力**：本平台為展示版本，結算幣、身分驗證及查驗簽章均為模擬，**鏈上額度不具法律效力，不得用於任何法定申報、碳費扣抵或對外宣告**。
二、**政策風險**：可扣抵比率與上限（碳費收費辦法第九條、第十條）及專案計入期（溫室氣體自願減量專案管理辦法第七條）得由主管機關調整。
三、**撤銷風險**：額度得因減量成效未實際發生或違反法規而經撤銷。
四、**請求權架構風險**：用戶之權利係對專案方之請求權，須經專案方配合始能完成官方移轉；專案方停業、清算或喪失事業資格時，得影響其實現，本公司僅能以第七條之上架資格限制及費用追繳機制促其履行。
五、**自然人限制**：自然人不得開立額度帳戶、不得申請註銷，其持有僅得以轉售實現價值（第三條之一）。
六、**金鑰風險**：passkey 遺失且無有效憑證可供回復者，資產可能無法取回。

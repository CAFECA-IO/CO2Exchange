# 減量額度註銷暨移轉委任書

**本文件為 Phase 0 展示範本，非法律意見，正式上線前應經法遵與律師審閱。**

## 第一條　委任人與受任人

委任人：於 TideBit-DeFi 碳權交易所持有本委任書所載鏈上額度之**事業**。本件標的為**國內減量額度**者，並須**已於環境部「溫室氣體減量額度管理系統」（tcerregistry.moenv.gov.tw，下稱官方登錄簿）開立額度帳戶**；本件標的為**國外減量額度**者，因無官方移轉程序（第二條之一第一款），不以開立國內額度帳戶為必要，但仍以事業為限。

**委任人資格限制**：依溫室氣體減量額度交易拍賣及移轉管理辦法第二條第一款，「事業」不含自然人；同辦法第七條開立額度帳戶須檢附經目的事業主管機關核准設立、登記或營業之證明文件。**自然人無從開立額度帳戶，不得簽署本委任書、亦不得申請註銷**；其鏈上額度僅得持有或再次出售。

受任人：卡菲卡金融科技股份有限公司（下稱「本公司」），為本平台之建置者與代營運者。本件標的為**國內減量額度**者，**本公司不持有該減量額度**——該額度依溫室氣體自願減量專案管理辦法第二十二條核撥後，全程登錄於專案方自有之額度帳戶內；本公司之地位為程序協辦人，非移轉之當事人，亦非註銷申請人。本件標的為**國外減量額度**者，該額度存放於本公司於核發國官方登錄簿開立之**託管帳戶**內，本公司自有錢包不持有額度，其註銷依第二條之一辦理。

**國外減量額度之委任人**：除前開事業資格外，委任人於**臺灣**申報而涉及氣候變遷因應法第二十七條之扣除或抵銷者，並應已取得中央主管機關之**認可**，或聲明其用途為自願性碳中和或碳抵換而不涉及該條之扣除或抵銷。認可由委任人自行申請，**本公司不代為申請，亦不保證取得**。

**本平台之國際性與法規適用之分層**：本平台為國際運行平台，同時交易多個轄區核發之減量額度。本委任關係——即委任人與本公司間就協辦事務所生之權利義務——依**中華民國法律**；但**本件標的之權利內容、移轉與註銷程序、可用途徑及申報效力，依該額度核發國之法規與該國官方登錄簿之規定**，不因其於本平台交易或委由本公司協辦而改變（「平台使用約定書」第一條之一）。本委任書所引中華民國之法規，係規範**在臺灣申報或使用**時之要件與限制，非本件標的全部之法規基礎。

## 第二條　委任範圍

**本條適用於標的為國內減量額度者；標的為國外減量額度者，依第二條之一。**

委任人茲委任本公司，就第三條所載減量額度**協辦**下列程序。本公司之工作為備文、送件、聯繫專案方與中央主管機關及進度追蹤；**移轉之一方為專案方與委任人，註銷申請人為委任人自己**。

一、**協辦官方移轉**：聯繫專案方，備齊交易後移轉所需文件，協助雙方向中央主管機關申請將該額度自**專案方額度帳戶移轉至委任人額度帳戶**。依溫室氣體減量額度交易拍賣及移轉管理辦法第二條第六款，移轉係完成交易後由中央主管機關為之；依同辦法第二十六條「每減量額度單位移轉次數，以一次為限」，本項移轉為該額度唯一一次之官方移轉。

二、**協辦註銷申請**：於移轉完成後，依同辦法第二十七條備妥註銷申請書及應登錄、上傳之資料，**以委任人名義**向中央主管機關申請註銷。

三、代為繳納規費、補正文件、回應主管機關之詢問與補件通知。

四、取得註銷證明後，於本平台發給不可轉讓之鏈上註銷憑證並公告。該憑證為本平台之紀錄，其法律效力以主管機關核發之註銷證明為準。

本委任不包含代為進行任何環境聲明、廣告宣告或第三方查證，亦不包含代委任人持有額度。

## 第二條之一　國外減量額度之委任範圍與限制

本件標的為國外減量額度者，除本條另有約定外，準用本委任書其餘條文。

一、**無官方移轉程序**：該額度自始存放於本公司於核發國官方登錄簿之託管帳戶內，鏈上易主不觸動該帳戶，故**無第二條第一款之官方移轉程序**。本公司之協辦工作為核對託管帳戶之持有數量，並依核發國登錄簿規則辦理註銷（retirement），或於該登錄簿規則允許時，移轉至委任人於該登錄簿之帳戶後由其自行註銷。

二、**在臺灣申報之前提——認可**：依氣候變遷因應法第二十七條，事業取得國外減量額度者，應經中央主管機關**認可**後，始得扣除同法第二十八條第一項各款之排放量或抵銷第三十六條第二項之超額量。委任人以該等用途委任註銷者，應於委任時檢附認可文件；未檢附者，本公司不受理該用途之委任。認可之要件、應備文件與作業時間依主管機關公告。本款為**在臺灣申報或使用**之要件；委任人於臺灣以外之轄區申報或使用者，依該轄區之法規辦理，並應自行檢附該轄區所要求之文件。

三、**在臺灣申報時之用途限制**：國外減量額度**不得**用於氣候變遷因應法第二十四條之溫室氣體增量抵換；環評承諾事項亦不得以國外減量額度履行。本平台註銷合約於**鏈上**擋下前開二類用途之註銷請求，該限制為技術性強制，非僅為介面提示。委任人就國外減量額度，僅得就第四條第二款之第 1 目（扣除碳費排放量）或第 2 目（自願性碳中和或碳抵換）擇一聲明。本款所列用途分類為中華民國法規之分類；委任人於其他轄區申報者，其用途之認定依該轄區法規，惟本平台之鏈上限制仍適用。

四、**在臺灣申報時之扣除上限**：依碳費收費辦法第十條，**非屬**經審查認定之高碳洩漏風險事業，以國外減量額度申請扣除收費排放量者，其**扣除上限不得超過事業收費排放量之百分之五**；高碳洩漏風險事業**不得**以國外減量額度扣除收費排放量。對照同辦法第九條，國內減量額度之扣除上限為收費排放量之**百分之十**，其中自願減量專案取得之減量額度，扣除比率為 **1.2**。實際可扣除數量以中央主管機關核定為準。

五、**相應調整**：委任人知悉巴黎協定第六條第二項之相應調整，係地主國授權其減量成果作國際用途時應為之調整；未為相應調整者，同一公噸溫室氣體減量將由地主國與使用國重複主張。**本公司不代表本件額度已取得相應調整之授權**，除非該批額度於上架資訊中另有載明。

六、**公開與宣告**：國外減量額度之註銷公開與環境聲明，依核發國登錄簿規則及中央主管機關認可所附條件辦理，第八條所定之國內公開程序不適用；於核發國登錄簿完成公開或核發註銷證明前，委任人同樣不得對外宣告。

七、**託管之揭露**：本件額度所屬轄區之託管帳戶持有數量、鏈上流通量及查核狀態，依「平台使用約定書」第八條之一按月揭露於本平台「託管揭露」頁（/custody）。

八、**註銷程序依核發國法規**：本件註銷之受理、程序、憑證形式、生效時點及其對外效力，均依**核發國**之法規與該國官方登錄簿之規定辦理。本公司之協辦不生變更該等規定之效果；該登錄簿規則變動、延宕、否准或要求補正者，依第十一條辦理。

九、**委任人之法遵義務**：委任人就其持有及註銷之本件額度，應自行遵守**核發國**之法規，及**其自身所在地或申報地**之法規，包括但不限於申報、認可、稅務與資訊揭露義務，並自行確認該額度得否用於其所聲明之用途。**本公司不提供法律意見**；委任人未盡前開義務所生之不利益，由委任人自負。

## 第七條　委任人之配合義務與逾期效果

委任人應於本公司通知所定期限內提供補正資料、簽署或用印必要文件。通知發送至委任人登錄之電子郵件信箱後**第三日推定送達**。

補正期限為通知送達後**七日內**；中央主管機關另定期限者，應於該期限屆滿前**二個工作日**完成。因不可歸責於委任人之事由未能遵期者，得於事由消滅後五日內檢具證明申請展延一次，以十四日為限。

經合法催告而逾期未補正者，本公司得暫停本件申辦程序並書面通知；暫停逾**六十日**仍未補正者，本公司得終止本委任，該額度回復為鏈上持有狀態，已收取之註銷代辦服務費不予退還。

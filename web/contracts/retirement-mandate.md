# 減量額度註銷暨移轉委任書

**本文件為 Phase 0 展示範本，非法律意見，正式上線前應經法遵與律師審閱。**

## 第一條　委任人與受任人

委任人：於 CO2Exchange 平台持有本委任書所載鏈上額度，且**已於環境部「溫室氣體減量額度管理系統」（tcerregistry.moenv.gov.tw，下稱官方登錄簿）開立額度帳戶之事業**。

**委任人資格限制**：依溫室氣體減量額度交易拍賣及移轉管理辦法第二條第一款，「事業」不含自然人；同辦法第七條開立額度帳戶須檢附經目的事業主管機關核准設立、登記或營業之證明文件。**自然人無從開立額度帳戶，不得簽署本委任書、亦不得申請註銷**；其鏈上額度僅得持有或再次出售。

受任人：卡菲卡股份有限公司（下稱「本公司」），為本平台之建置者與代營運者。**本公司不持有本件減量額度**——該額度依溫室氣體自願減量專案管理辦法第二十二條核撥後，全程登錄於專案方自有之額度帳戶內；本公司之地位為程序協辦人，非移轉之當事人，亦非註銷申請人。

## 第二條　委任範圍

委任人茲委任本公司，就第三條所載減量額度**協辦**下列程序。本公司之工作為備文、送件、聯繫專案方與中央主管機關及進度追蹤；**移轉之一方為專案方與委任人，註銷申請人為委任人自己**。

一、**協辦官方移轉**：聯繫專案方，備齊交易後移轉所需文件，協助雙方向中央主管機關申請將該額度自**專案方額度帳戶移轉至委任人額度帳戶**。依溫室氣體減量額度交易拍賣及移轉管理辦法第二條第六款，移轉係完成交易後由中央主管機關為之；依同辦法第二十六條「每減量額度單位移轉次數，以一次為限」，本項移轉為該額度唯一一次之官方移轉。

二、**協辦註銷申請**：於移轉完成後，依同辦法第二十七條備妥註銷申請書及應登錄、上傳之資料，**以委任人名義**向中央主管機關申請註銷。

三、代為繳納規費、補正文件、回應主管機關之詢問與補件通知。

四、取得註銷證明後，於本平台發給不可轉讓之鏈上註銷憑證並公告。該憑證為本平台之紀錄，其法律效力以主管機關核發之註銷證明為準。

本委任不包含代為進行任何環境聲明、廣告宣告或第三方查證，亦不包含代委任人持有額度。

## 第四條　受益人資料與用途聲明

**（一）受益人資料**　委任人應提供受益人（即額度使用者）之名稱或姓名、統一編號或身分證統一編號、地址、聯絡人、電話及電子郵件。

依溫室氣體減量額度交易拍賣及移轉管理辦法第二十七條，使用用途之對象**限於該額度帳戶之事業**；委任人聲明所填受益人符合前開限制，或同意由本公司依主管機關認可之代辦方式辦理。

**（二）用途聲明**　委任人應就下列四類用途**擇一**聲明並填載說明：

1. **扣除碳費排放量**：載明適用年度及收費排放量。委任人知悉碳費收費辦法第九條、第十條就扣除比率及上限另有規定，實際可扣除數量以中央主管機關核定為準。
2. **自願性碳中和或碳抵換**：載明宣告標的（產品、服務、活動或組織）及涵蓋期間。
3. **溫室氣體增量抵換**：載明抵換義務之來源文件字號。
4. **環評承諾事項**：載明環境影響評估審查結論之公告字號及承諾條款。

## 第五條　委任人之保證與聲明

委任人保證並聲明：

一、**委任人為事業，且已於官方登錄簿開立有效額度帳戶**，所登錄之帳戶編號正確、未經凍結或註銷。
二、所提供之受益人資料、用途聲明及一切文件均真實、正確、完整，且於本委任存續期間持續有效。
三、對本委任標的有完整請求權，該額度未經註銷、未設定負擔、未經法院或行政機關扣押或凍結。
四、**不重複主張**：同一額度不曾且不會於其他碳權制度、自願性標準、國際機制或其他申報管道重複登錄、使用或宣告。
五、所聲明用途嗣後變更者，應於變更事由發生後**七日內**通知本公司；本公司尚未送件前得申請更正。

違反前項保證致本公司或第三人受有損害者，應負賠償責任，範圍以相當因果關係之實際損害為限；有故意或重大過失者並負回復原狀之責。

## 第六條　辦理期程與通知

本公司應依下列期程辦理，並於各節點以站內通知併同電子郵件通知委任人：

| 階段 | 期限 |
|---|---|
| 收件形式審查、回覆補件事項 | 受理委任後 **三個工作日**內 |
| 聯繫專案方並協助送出交易後移轉申請 | 資料齊備後 **十個工作日**內 |
| 移轉完成後以委任人名義送出註銷申請 | 接獲移轉完成通知後 **五個工作日**內 |
| 取得註銷證明後發給鏈上註銷憑證並公告 | 取得證明後 **三個工作日**內 |

主管機關審查所需時間不計入前開期限。因可歸責於本公司之事由逾期者，應減免該筆代辦服務費；逾期達三十日者全額退還。

## 第七條　委任人之配合義務與逾期效果

委任人應於本公司通知所定期限內提供補正資料、簽署或用印必要文件。通知發送至委任人登錄之電子郵件信箱後**第三日推定送達**。

補正期限為通知送達後**七日內**；中央主管機關另定期限者，應於該期限屆滿前**二個工作日**完成。因不可歸責於委任人之事由未能遵期者，得於事由消滅後五日內檢具證明申請展延一次，以十四日為限。

經合法催告而逾期未補正者，本公司得暫停本件申辦程序並書面通知；暫停逾**六十日**仍未補正者，本公司得終止本委任，該額度回復為鏈上持有狀態，已收取之註銷代辦服務費不予退還。

**專案方不配合移轉時之處理**：本件官方移轉須專案方配合始能完成。專案方拒絕或無故拖延者，本公司應於知悉後**三個工作日內**通知委任人，並依「代辦服務費用與減免約定書」第六條第二款停止其上架資格、**追繳已減免之每噸代辦費**，必要時依該約定書第八條自其待結算價金中抵充。委任人得擇一為之：一、依「減量額度買賣定型化契約」第七條之一請求本公司以**等值額度替換**（第一順位救濟）；二、等待本公司依該約定書第七條催告專案方（催告送達後三十日）；三、終止本委任並請求退還已繳之註銷代辦服務費；四、將該鏈上額度於本平台再次出售。專案方之給付不能致委任人受有損害者，委任人得依「減量額度買賣定型化契約」第七條逕向專案方請求，追繳金額於計算賠償時應予扣除。

委任人自己即為專案方（就自有專案額度申請註銷）者，其不配合依前開約定書第六條處理，效果同前項。

## 第八條　公開後始得宣告之限制

依溫室氣體減量額度交易拍賣及移轉管理辦法第二十七條，中央主管機關應於註銷次日起**五個工作日內**，將減量額度用途及說明公開於指定資訊平台；**經公開後，事業始得將使用情形對外進行環境聲明或宣告**。

委任人承諾於主管機關完成公開前，不以任何形式（含新聞稿、廣告、產品標示、永續報告書、社群媒體）對外宣稱已完成碳中和、碳抵換或碳費扣抵。

本公司應於確認官方公開後**一個工作日**內通知委任人，並於鏈上公告欄註記公開日期。違反本條者其法律責任由委任人自負。**Phase 0 展示階段之鏈上註銷憑證為模擬文件，不具法律效力，不得作為任何宣告之依據。**

## 第九條　費用

註銷代辦服務費依費用頁面公告之費率按件計收，於委任成立時收取。主管機關依法收取之規費由本公司代墊後向委任人請求，並檢附繳費證明。因可歸責於委任人之事由須重新送件者，其重辦規費及必要費用由委任人負擔。

## 第十條　委任之終止與撤回限制

委任人於**尚未向中央主管機關送出移轉申請前**，得隨時以平台介面終止本委任，本公司應退還已收取之代辦服務費，但已代墊規費不予退還。

**已送出申請後**，因官方程序不可逆，委任人不得逕行撤回；但得請求本公司代為向主管機關申請撤回，能否撤回依主管機關決定，本公司不負撤回成功之擔保責任。

有下列情形之一者，本公司得終止本委任並敘明理由通知：委任人違反第五條保證；依第七條經催告逾六十日未補正；該額度經中央主管機關撤銷、凍結或註記無效。

## 第十一條　責任範圍

本公司辦理本委任事務應盡善良管理人之注意義務，並將辦理進度與主管機關來文即時轉知委任人。

因可歸責於本公司之事由致委任人受有損害者，賠償範圍以相當因果關係之實際損害為限，並以本件代辦服務費之**十倍**為上限；有故意或重大過失者不受上限限制。

主管機關駁回申請、要求補正、變更見解或延宕審查，**以及專案方遲延或拒絕配合移轉**，均非可歸責於本公司，本公司不負賠償責任；但應協助委任人依指示補正或重新申請，並依「代辦服務費用與減免約定書」對不配合之專案方停止其上架資格、追繳已減免之代辦費。專案方之給付不能致委任人受有損害者，委任人得逕向專案方請求。

## 第十二條　準據法與管轄法院

本委任書以中華民國法律為準據法。所生爭議雙方應先本於誠信協商；協商不成者，合意以**臺灣臺北地方法院**為第一審管轄法院。委任人為消費者時，不排除其依消費者保護法得主張之權利。
